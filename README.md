# 📘 FB Clone Website

This project is a **Facebook website clone** created as part of my **Git and GitHub learning tutorial**. The main purpose of this project was to practice Git commands and understand how to manage a project using Git and GitHub.

## 🚀 About the Project

The **FB Clone Website** is a simple web project inspired by the design and layout of Facebook. It was created for learning and practice purposes and is **not affiliated with or connected to Facebook or Meta**.

While developing this project, I practiced working with source code, making changes, tracking those changes, creating commits, and uploading the project to a GitHub repository.

## 🎯 Learning Objectives

The main objectives of this project were:

* Learn the basics of **Git**
* Understand how to create and manage a Git repository
* Practice `git init`, `git add`, `git commit`, and `git push`
* Learn how to connect a local project with **GitHub**
* Understand how to track changes in a project
* Practice organizing project files
* Learn the basic workflow of Git and GitHub

## 💻 How to Run the Project

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder:

```bash
cd fb-clone-website
```

3. Open `index.html` in your web browser.

You can also open the project using **VS Code** and use a live server extension to view the website.
